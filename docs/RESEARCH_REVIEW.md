## 1. 项目现状分析

### 1.1 数据资产

2015 年 12 月以单一种子用户（zhao-che）BFS 两层爬取的知乎快照，SQLite 存储（688MB，
现存于百度盘，仓库内无数据文件）：

| 表 | 规模 | 内容 | 观测完整性 |
|---|---|---|---|
| User | 26,161 | 画像五计数 + layer | 画像计数为全站真实值 |
| Following | 4.6M | 有向关注边 | 仅 26k 用户间诱导子图完整（约 23 万条边量级） |
| Question | 2.2M | 问题-话题标签 | 已知有 topic 爬漏（比例待量化） |
| UserQuestion | 1.7M | 用户回答过的问题 | — |
| UserTopic | 5.4M | 用户-话题（带重复计数） | 依赖 Question 表的话题覆盖 |

三个结构性约束决定了一切后续研究的边界：

1. **采样框**：两层雪球采样 + 单一种子。26k 用户不是知乎的随机样本，而是
   "种子的两步关注可达集合"——系统性偏向活跃、高知名度用户（第 4 节用模拟量化）。
2. **无时间、无文本**：不能做任何动态/演化分析和内容分析；能做的是结构 × 兴趣标签。
3. **快照年代**：2015 年 12 月，知乎注册用户约 3000 万的时期。作为"当下数据"已失效，
   作为"历史切片"反而稀缺（知乎官方从未发布过关注网络数据；ZhihuRec 也只有交互日志）。

### 1.2 已有分析工作（2015 报告结论摘要）

- 五个画像特征的 log-log 散点"显著幂律"→ 推断知乎结构类似 Twitter 型社交网络；
- agree 与 follower 计数正相关（散点目测）；
- Net10k（agree>1 万，1896 人）密度 0.064，Net50k（agree>5 万，375 人）密度 0.195
  → 推断"高赞用户之间抱团"；
- Net10k 强连通分量 [1853, 1×42]，平均最短路 2.11；Net50k [368, 1×7]，1.85
  → "大陆 + 孤岛"结构，精英层高度互连；
- PageRank/HITS Top5：知乎联合创始人 jixin 居首，作家群体（zhang-jia-wei、
  ma-bo-yong 等）占据 authority 头部；
- 支配集 + 话题频次 → 热门话题为生活/历史/电影。

这些结论的方法学问题见第 3 节——它们构成了"重访"研究的全部出发点。

## 2. 文献综述

### 2.1 知乎作为研究对象

知乎相关的学术工作在 2015 年后明显增多，主要线索：

- **专家发现**：[ZhihuRank](https://link.springer.com/chapter/10.1007/978-3-319-25515-6_15)
  （2015，就是用知乎数据提出的话题敏感专家排序算法，LDA 话题建模 + 话题加权
  PageRank）；[基于知乎的用户影响力与 KOL 识别](https://www.lis.ac.cn/EN/10.13266/j.issn.0252-3116.2018.20.014)
  （2018，改进 PageRank/HITS，与本项目 2015 年的做法直接同源）。
- **社区结构与情绪**：[知乎问答社区情绪极化机制](https://www.frontiersin.org/journals/physics/articles/10.3389/fphy.2023.1139475/full)
  （2023，SNA + 深度学习，发现核心话题上的小世界现象）；
  [WHICEB 2020 知乎知识交换平台 SNA](https://aisel.aisnet.org/whiceb2020/3/)。
- **公开数据集**：[ZhihuRec](https://github.com/THUIR/ZhihuRec-Dataset)
  （清华 THUIR × 知乎官方，2021，约 1 亿条推荐交互日志，含用户/回答/问题/话题
  侧信息）——目前最大的知乎公开数据集，但**不含关注网络**；
  [知乎专家识别数据集](https://arxiv.org/abs/1711.05350)（120 万训练对）。
- 结论：**知乎的关注网络结构数据在公开研究中始终稀缺**，本数据集的差异化价值在此。

### 2.2 CQA 专家发现与问题路由

- 系统综述：[A Survey on Expert Recommendation in CQA](https://arxiv.org/abs/1807.05540)
  （JCST 2018）把方法谱系分为矩阵分解 / 图方法（PageRank、HITS 变体）/
  话题模型（LDA 系）/ 深度学习四类；
  [Emerald 2019 综述](https://www.emerald.com/insight/content/doi/10.1108/ijcs-03-2019-0011/full/html)
  补充了画像建模—推荐方法—系统影响的三层框架。
- 近期方向：[结合话题特异性与社交关系的专家发现](https://arxiv.org/pdf/2407.04018)
  （2024）、[话题社区 + 时序专长的问题路由](https://arxiv.org/pdf/2207.01753)（2022）。
- 对本项目的含义：本数据集**同时拥有关注网络和用户-话题二部图**，恰好是
  "社交关系 × 话题特异性"这条最新线索需要的数据形态；2015 年只做了全局
  PageRank/HITS，话题敏感化（分话题专家榜 + agree_num 外部验证）是直接可做的增量。

### 2.3 网络科学方法论：幂律之争

- [Broido & Clauset, *Scale-free networks are rare*, Nature Communications 2019](https://www.nature.com/articles/s41467-019-08746-5)：
  对近 1000 个网络用 Clauset–Shalizi–Newman（CSN）框架做严格检验，
  仅约 4% 满足最强无标度判据，多数网络对数正态拟合不差于幂律。
- 反方：Voitalov 等认为若允许小度端偏离，无标度网络并不罕见；
  [Serafino et al., PNAS 2021](https://www.pnas.org/doi/10.1073/pnas.2013825118)
  提出有限尺寸效应会掩盖真实的无标度性。争论的技术核心是 x_min 选择、
  纯幂律 vs 正则变化尾、以及有限样本下的检验功效。
- 工具链成熟：`powerlaw` 包（Alstott et al.）实现了 CSN 全流程
  （MLE、KS 选 x_min、似然比检验）。
- 对本项目的含义：2015 年"log-log 目测幂律"的结论按当下标准必须重做；
  用中文知识社区数据给这场辩论补充数据点，是一篇小而完整、结论无论正反都有
  发表价值的再分析。

### 2.4 图遍历采样偏差

- [Kurant et al., *On the bias of BFS*, 2010](https://arxiv.org/abs/1004.1729)：
  证明不完整 BFS（以及 DFS、雪球、森林火）系统性偏向高度数节点，并对随机图
  给出解析校正；[Towards Unbiased BFS Sampling, 2011](https://arxiv.org/pdf/1102.4599)
  给出实用校正器，但指出对有强社区结构的真实图只是启发式。
- [Gjoka et al., *A Walk in Facebook*, 2010](https://arxiv.org/pdf/0906.0060)：
  确立了 re-weighted random walk / Metropolis-Hastings random walk 作为
  OSN 无偏采样的标准做法——反衬 BFS 爬取数据在分布估计上的固有缺陷。
- 对本项目的含义：本数据集正是文献中偏差最重的情形（单种子、仅两层、有向图只沿
  出边扩展）。第 4 节的模拟实验证实了偏差的方向和量级。

### 2.5 图机器学习：嵌入与链路预测

- 浅层嵌入：[node2vec, KDD 2016](https://arxiv.org/abs/1607.00653)；
  归纳式 GNN：GraphSAGE（NeurIPS 2017）。
- 评测方法论警示：[Evaluating GNNs for Link Prediction (HeaRT), 2023](https://arxiv.org/abs/2306.10453)
  指出既有基准的负采样方式严重高估模型差距；
  [Revisiting Link Prediction: A Data Perspective, 2023](https://arxiv.org/pdf/2310.00793)
  论证不同数据集上起作用的因子（局部结构 / 特征同质性 / 全局结构）不同。
- 对本项目的含义：26k 节点的诱导子图规模适中，适合做"话题特征对关注预测的增量
  贡献"这类消融研究；必须按 HeaRT 式规范做负采样，否则结论不可信。

### 2.6 异质网络与社区检测

- [兴趣驱动的属性异质网络社区检测, Information Fusion 2024](http://w.sentic.net/interest-driven-community-detection.pdf)；
  [结构 + 时序内容嵌入的用户社区检测, Information Sciences 2019](https://www.sciencedirect.com/science/article/abs/pii/S030645731830997X)；
  [CQA 异质内容网络嵌入做专家推荐, 2023](https://www.techscience.com/cmc/v75n1/51490/html)。
- 社区检测本体：Leiden 算法（2019）取代 Louvain 成为默认选择（保证连通社区、
  质量更稳）；共识聚类用于对抗随机性。
- 对本项目的含义：User–Following–Question–Topic 天然构成异质信息网络；
  "社交社区 × 兴趣聚类对齐度"（RQ3/RQ4）在知乎数据上未见先例，是主线研究的空位。

### 2.7 LLM 时代的交叉点

- [LLM 驱动社会仿真综述, 2024](https://arxiv.org/abs/2412.03563)（S³、OASIS
  百万智能体、AgentSociety 等）：该方向普遍缺**真实网络快照**做初始化与校准，
  历史快照数据是潜在的稀缺输入（[资源列表](https://github.com/tsinghua-fib-lab/LLM-Agent-Based-Modeling-and-Simulation)）。
- 中文语义嵌入成熟（bge 系列等）：使 540 万条 UserTopic 的话题标签可以做语义
  聚类，修复 2015 年字符串精确匹配的粒度问题（"恋爱/爱情/情感"三分）。

## 3. 2015 年方法的批判性检视

这是"重访"文章的骨架：逐条列出当年结论、问题所在、以及现代做法。

| # | 2015 年做法/结论 | 问题 | 现代做法 |
|---|---|---|---|
| C1 | log-log 散点目测 → "显著幂律" | 视觉判断无检验功效；log-log 直线对多种重尾分布都成立 | CSN：MLE + KS 选 x_min + bootstrap GOF + 对数正态似然比（§2.3） |
| C2 | 画像计数分布代表知乎整体 | 样本 = BFS 两层可达集，高度数节点被过采，分布尾部被系统性夸大 | 采样偏差模拟给出偏差量级（§4）；结论限定在采样框内 |
| C3 | 以 agree_num 阈值选 Net10k/Net50k 再算密度/中心性 → "精英抱团" | 以结果变量选样本（selection on outcome）：高赞用户密度高可能只是"可见性 × 度"的副产品，需要与度保持零模型对比 | 与 configuration model 重连基线比较密度/互惠率，才能说"超出度结构预期的抱团" |
| C4 | 有向图上的 closeness"约 0.5 → 用户地位平等" | 有悬挂节点（closeness=0）混入；有向不连通图的 closeness 定义本身含糊；当年 networkx 的最短路实现也被报告自己质疑 | igraph 上用 harmonic centrality（对不连通图良定义），报告分布而非均值印象 |
| C5 | 支配集频次 → 热门话题榜 | 支配集不唯一且贪心近似任意性强；话题按字符串精确计数，同义标签被拆分 | 语义聚类后的话题簇计数；或直接对全体（而非支配集）做 TF-IDF 加权 |
| C6 | PageRank/HITS 全局榜 | 只有全局榜，混淆了"全平台名人"与"领域专家" | 话题敏感 PageRank 分领域出榜，用 agree_num 验证（§2.2） |

C2 是全局性的：它不否定当年工作（受当时算力与知识约束，属课程项目正常水准），
但意味着**任何把该数据当作"知乎整体"的推断都需要偏差声明**。这也是为什么执行
计划把项目一（严谨化）放在项目二（新研究）之前。

## 4. 先行实验：BFS 采样偏差模拟

已完成并可复现（`python -m analysis.run_all --bfs-bias --out results`，
不需要真实数据；结果在 `results/bfs_bias_simulation.md`）。

**设计**：10 万节点有向配置模型，入度植入纯幂律；出度取"常数基底 + 幂律尾"
使均值 ≈ 50（贴近真实关注行为的量级；拟合对象只是入度）。从 10 个独立种子
（出度 100–400，模仿真实种子用户 149 关注）各做一次两层 BFS，比较三种入度分布估计。

**结果**（细节见 results/）：

| 估计方式 | 拟合 α | 相对真值的偏差 |
|---|---|---|
| 全图真实入度 | 2.98 | — |
| 被采样节点的画像计数 | 2.38 ± 0.16 | **低估 0.60** |
| 诱导子图入度 | 2.63 ± 0.15 | 低估 0.35 |

**核心发现（修正了执行计划中的预判）**：原计划假设"画像计数可信、诱导子图度不可信"。
实验显示画像计数的分布偏差反而更大——每个数值本身真实，但 BFS 决定了**谁进入样本**：
两层可达集过采高入度节点，使观测分布尾部变重、指数被低估约 0.6。诱导子图度则叠加
两种反向偏差（节点过采 vs 边截断），净偏差反而略小，但方差和不可预期性更高。

**对真实数据分析的含义**：
1. 2015 报告 4.2 节五张 log-log 图（基于画像计数）不仅有 C1 的检验问题，
   样本构成本身就有系统性偏斜——重访文章的最有力论点；
2. 真实数据上拟合出的 α 应报告为"采样框内估计"，并引用本模拟给出偏差方向
   （真实全站指数大概率比观测值更陡）；
3. 后续可做敏感性分析：在模拟中变化种子度数、层数、出度均值，看偏差量级的稳健性。

## 5. 研究机会评估与取舍

综合 §2–§4，机会按"数据契合度 × 文献空位 × 成本"评估（完整清单见 ROADMAP）：

**采纳为主线**：
- **项目一：严谨幂律重访**（§2.3 + §2.4 + §3 的 C1/C2）。成本最低，文献对话明确
  （加入 Broido–Clauset 之争），先行实验已提供独立于真实数据的核心论据。
- **项目二：社交社区 × 兴趣社区对齐**（§2.6）。数据形态独有（关注网络 + 话题
  二部图并存），研究问题（"跟人走还是跟兴趣走"）在知乎数据上无先例，
  且直接回答 2015 项目提出但未解决的原始问题。

**评估后搁置**：
- **与 ZhihuRec 纵向对比**：口径差异过大——ZhihuRec 是推荐系统曝光/点击日志
  （2021），本数据是关注网络快照（2015），用户群、字段、采样机制均不可比，
  只能得到描述性对照，不构成严谨的纵向研究。（用户已确认此判断。）
- **精英用户十年回访**：需要重新爬取，知乎反爬与合规成本高；保留为远期选项。
- **LLM 仿真校准**（§2.7）：有价值但属于另一个研究共同体的工程量，适合作为
  合作项目而非独立推进。
- **爬虫修复、回答文本挖掘**：前者成本/收益不成立，后者缺数据，均不做。

### 6.1 附：本数据集的对外使用情况调查（2026-07）

多角度搜索（项目名精确匹配、百度盘链接、简书文章标题、GitHub/Gitee 域内检索、
arXiv）**未发现任何公开发表的论文、学位论文或预印本明确引用本项目或数据集**。
可确认的使用痕迹停留在仓库层面：212 stars / 144 forks，若干 issue
（多与爬虫相关，提示大部分关注来自爬虫而非数据集本身）。

调查存在两个盲区：(1) 本环境无法访问 Semantic Scholar / OpenAlex / 知网 / 万方，
中文学位论文——通过简书+百度盘分发的数据集最可能的使用场景——恰恰集中在
知网/万方；(2) 百度盘直接下载不留归属痕迹，"静默使用"无法从公开网络观测。
建议仓库所有者自行核查三处高信号位置：百度盘分享的**保存/下载次数统计**、
简书两篇文章的评论区、GitHub fork 列表与 stargazers 构成。

这一调查结果反过来支持路线图中"正式发布数据集"的建议：挂 DOI（Zenodo）并在
README 写明引用格式，才能把未来的使用转化为可见的引用。
