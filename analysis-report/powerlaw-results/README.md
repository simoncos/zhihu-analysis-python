# Profile-only comparison archive

This directory preserves the five-profile-series output produced on the
literature-review branch. It does not include bootstrap goodness-of-fit tests
or induced-subgraph degrees and is not the canonical result source.

Use `../../results/powerlaw_results.md` and the `analysis/` pipeline for
current work. In particular, a model beating the pure power law does not by
itself establish whether lognormal or truncated power law is the better
alternative; the canonical pipeline compares those alternatives directly.
